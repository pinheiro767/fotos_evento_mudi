# MUDI em Movimento — versão corrigida, SEM CORTES

Nesta versão, os **6 folders (1024 × 1536, formato vertical 2:3)** e os **3 vídeos verticais** são exibidos integralmente, com `object-fit: contain` e sem sobreposição de controles sobre as imagens no celular.

- As faixas vazias nas laterais de TVs e monitores horizontais são normais: preservam o formato vertical **sem recortar**.
- Para exibição maior, use **Tela cheia**. No celular, deslize para a esquerda/direita ou utilize **Anterior / Próximo** abaixo do folder.
- Para examinar detalhes de um folder, use **Ampliar** e **Restaurar** (100% = imagem inteira no visor).
- As fotos e vídeos foram preservados sem alterações. A correção foi no layout, não nas artes.

## Instalação / publicação

1. Descompacte este ZIP.
2. Envie todo o conteúdo (incluindo as pastas `assets` e `icons`) para a raiz do seu repositório no GitHub.
3. Ative **Settings → Pages → Deploy from a branch → main / (root)**.
4. Acesse o endereço HTTPS fornecido pelo GitHub Pages e pressione **Instalar aplicativo** (ou use o comando de adicionar à tela inicial no celular).
5. Se já publicou uma versão anterior, **substitua todos os arquivos antigos e atualize a página**; se ainda mostrar a versão antiga por causa do cache offline, feche todas as abas do app e reabra/atualize. O cache da nova versão é `v2-sem-cortes`.

## Uso

- A apresentação tem avanço manual, automático, repetição e ajustes de tempo.
- Os três vídeos podem ser incluídos ou excluídos, com opção de áudio.
- Use em TV/projetor com a opção **Tela cheia** para aproveitar melhor o espaço disponível.
- Para uso offline, abra o aplicativo conectado uma primeira vez e aguarde que as mídias sejam armazenadas. Os vídeos são arquivos maiores e precisam ser carregados para estar disponíveis sem internet.
